# Buck-Converter-using-MATLAB
This Project contains the Buck Converter Design, ready to do simulations using MATLAB.

The Buck Converter basically trims the input voltage using Semiconductor Switch (eg. MOSFET) to acheive a lower value Output voltage.

We can use the Simulink Model to check the behaviour of output Voltage and current with various types of Semiconductor Switches 
- MOSFET
- IGBT
- BJT

We can also deduce the Inductor and Capacitor values using the Script.
The critical values of L and C can also be checked with the script.
